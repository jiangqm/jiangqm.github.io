时间轴编排

Timeline

用 GSAP Timeline 将多个动画步骤串联编排，通过 position 参数精确控制时序重叠与衔接。

参数控制

播放速度1
缓动函数

Timeline Choreography

Timeline 编排代码

const tl = gsap.timeline({ defaults: { ease: "power3.inOut" } })

tl.from(".circle", { scale: 0, autoAlpha: 0, duration: 0.6 })
  .from(".bar-1", { scaleX: 0, duration: 0.5 }, "-=0.2")
  .from(".bar-2", { scaleX: 0, duration: 0.5 }, "-=0.3")
  .from(".label", { y: 20, autoAlpha: 0, duration: 0.4 })
  .to(".circle", { rotation: 360, duration: 1.2, ease: "none" })
